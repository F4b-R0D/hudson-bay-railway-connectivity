# Hudson Bay Railway Connectivity Shock

**Connectivity disruptions · Causal inference · Spatial econometrics · Northern Canada**

This repository contains the reproducible workflow for the research project:

> **Connectivity Disruptions and Demographic Resilience in Remote Canada: The Hudson Bay Railway Corridor, 1996–2021**

## Research Question

How did the 2017 Hudson Bay Railway disruption affect population, employment, and socioeconomic resilience in remote communities along the corridor?

## Empirical Setting

The project studies the temporary loss of rail connectivity between Gillam and Churchill following the 2017 washouts and evaluates heterogeneous effects across communities with different levels of exposure to the railway corridor.

## Empirical Design

The analysis combines Canadian Census data, GIS-based infrastructure exposure, and quasi-experimental methods.

**Methods:** `Difference-in-Differences` · `Event Studies` · `Fixed Effects` · `Synthetic Control` · `Spatial Exposure` · `Moran's I` · `LISA`

## Repository Structure

- `notebooks/` — analysis and robustness notebooks
- `src/` — reusable data-processing and estimation code
- `data/` — data documentation and source notes
- `figures/` — maps, event-study figures, and diagnostics

## Status

**Work in progress.** Results are preliminary and the empirical design is still being refined. Public source data will be documented here; restricted or non-redistributable material will not be committed.
